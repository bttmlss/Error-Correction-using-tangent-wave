# The Correction Trajectory Atlas — one-page brief

**Question.** Do correction trajectories pass through recurring, ordered dynamical states — a "universal grammar of correction"? (Conceived with ChatGPT, 2026-10-07.)

**Phase 0 — pilot (200 trajectories).** 2 substrates (toy first-order nonlinear plant; Qwen2.5-0.5B layer-23 hidden states) × 2 controller regimes (frozen V4 law β<0 vs sign-flipped β>0), full per-timestep traces (e, Δe, Δ²e, action, reward), unsupervised k-means discovery. Result: the bar passed (transition entropy below shuffled null, z=−8..−77; sequences recur cross-substrate) but only **2 natural states** emerged — hard-correction-when-far → cruise-when-near, i.e., what elementary control predicts. A third "knocked off course" state was experimenter-induced (all 52 disruption steps within 2 steps of injected impulses). Side finding: the same β<0 law damps a first-order plant but anti-damps a second-order pendulum — β's role flips with plant order.

**Phase 1a — survival test (~1,600 trajectories).** Narrowed question (Adrian): does the two-state grammar survive across perturbation types, starting distances, noise levels, plant classes? Claude's pre-run review (6 points) found the draft couldn't fail — its bars passed on plain exponential decay — so the spec was hardened *before any run*: **Bar 0** (decisive one-state null: per-trajectory log-e change-point, one vs two slopes, ΔBIC; no-grammar controls — constant-step controller and pure e←(1−α)e decay through the identical pipeline; k-sweep from k=1; **≥75% one-slope → retire the claim**), 10× directionality bar (replacing a near-vacuous top-3 rule), σ=0 as negative control (predict an *unstable* partition boundary), cross-plant/cross-controller recurrence (toy↔L23 already guaranteed by earlier work), H1/H2 handoff predictions (fixed fraction of e₀ vs fixed absolute error, change-point-defined, powered at 50/trajectory-tercile).

**Phase 1a verdict: RETIRED.** Pooled one-slope fraction 0.785 ≥ 0.75. Plainly: "hard→cruise" was Δe shrinking with e, partitioned in feature space. True null, not power failure: labeled perturbation arms *do* show two-slope structure (k*=2, silhouette 0.874 — the pipeline finds real kinks); pure-decay controls correctly one-slope (97%); σ=0 over-splits (k*=4 — manufacture mode, characterized); directionality fails everywhere except the labeled impulse arm; centroid correspondence fails in all pools. The 1b gate does not fire.

**Post-1a adjudication (Claude's 5-point correction, conceded).** The honest conclusion narrows: "1a did not establish a reproducible two-state grammar" ≠ "universal one-slope dynamics." The pooled 78.5% mixes resolution-limited L23 cells (~10 steps/trajectory) with injected-kink arms; powered cells are uncomfortable (toy/damping 0.72 alone — below the bar; 28% two-slope vs 5% FPR). Biggest theoretical correction: the pendulum result is *linear systems theory, not evidence* — linear controller + linear plant → sum of exponentials → slowest mode dominates → one-slope is derived, not discovered. Regimes can only come from floors, saturation, switching, or disturbances — exactly where the pipeline did find them. And: a synthetic atlas cannot discover what it programmed; its temporal structure was ours.

**Close-out (pure re-analysis).** Retirement robust at/above calibrated thresholds (powered null pool 0.905 at ΔBIC 25; identical under multiplicative/additive nulls). The toy's excess kinks are genuine but the wrong kind: e_cp ≈ 40× the noise floor, early in the trajectory → deterministic controller transient (β wind-up from zero-padded Δe) plus mild cubic-drift curvature — not noise-floor artifacts, not states (no recurrence, no directionality). Pendulum kinks sit at the settle tolerance (floor effects). New methodological finding: null ΔBIC is strongly n-dependent (95th percentile 19@8 → 2009@200) — kink tests must calibrate n-conditionally. Synthetic atlas **FROZEN** on the two-state question.

**Pivot: LLM revision-loop atlas.** Observe a genuinely unknown correction process: an LLM revising its own answers across 8 fixed neutral rounds with **no α/β/γ imposed** (anti-circularity rule). Frozen error signal in three separated layers — task correctness → exact match (deterministic, zero noise floor); continuous measurement → frozen embedding distance (pinned checkpoint, no LLM-judge anywhere in the measurement path); temporal inference → Bar 0. Bar 0 runs first with n-conditional calibration; retirement scope-bound to "this model × task family × revision prompt × measurement × horizon."

**Stage 0 (synthetic validation of the instrument): FAIL.** Metric layer 9/9, single-regime nulls 95.5% correctly one-regime, but kink recovery 0.29 vs the 0.90 bar — the 5-parameter free-intercept model overfits noise at n=9 (discontinuity bias: solve events 0.97, smooth transitions 0.09–0.44). **Stage 0.1: FAIL.** Constrained continuous piecewise-linear model (4 params); null protection held (0.958) but power still failed (0.11–0.38) — near-oracle-efficient, so this is an SNR wall, not misspecification (σ=0.02 → 0.92–0.99 recovery; σ≥0.05 → collapse; lengthening trajectories can't fix it). **Stage 0.2 (running): targeted pattern battery.** Track A solve (deterministic exact-match flags); B1 stall, B2 oscillation, B3 divergence (each with frozen operational definitions); B4 residual kink (auxiliary only, above the SNR boundary). Thresholds by *empirical* null calibration only; ≤5% false-positive rate per detector plus family-wise FPR reported; ≥90% recovery on synthetic gross patterns. Scope hard-limited to instrument validation: "can the frozen pipeline recognize X without calling ordinary trajectories X?" **Zero LLM calls spent to date** — the staged validation keeps catching instrument failures before trajectories are spent.

**Standing principles.** Bar 0 must be capable of killing the state hypothesis before any clustering interprets trajectories. Don't ask the atlas to discover states until a state model is demonstrated necessary. Pre-register everything, including null branches and retirement rules; failed bars are findings; models under test are "volunteers"; plain-language-first write-ups.
